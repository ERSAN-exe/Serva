# 项目简介

**Serva —— 现代化的 Windows 文件比较与同步工具**

Serva 是一款轻量、高性能的桌面应用程序，专为 Windows 10 和 Windows 11 设计，提供文件夹比较与文件同步功能。应用基于 WinUI 3 和 .NET 10 构建，采用简洁现代的界面，帮助你轻松比较目录内容、预览同步方案，并保持本地文件夹与外部存储设备中的文件同步。
